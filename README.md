# タイムズカー料金比較

タイムズカーシェア(ベーシッククラス・九条駅前発着)の「深夜パック」と「通常の時間料金」を比較し、どちらが安いか一目でわかるツールです。

- 出発時刻・利用時間・走行距離を入力すると自動で比較
- 行き先の場所名を入力すると、OpenStreetMap(Nominatim/OSRM)を使って往復の走行距離を自動計算
- 実際の利用明細(複数件)と照合し、計算ロジックの正確性を確認済み

## 料金の前提

タイムズカーシェア公式サイトの公開料金(ベーシッククラス)をもとに計算しています。

- 時間料金: 15分220円
- 最大時間料金: 6h上限4,290円 / 12h上限5,500円 / 24h上限6,600円 / 36h上限8,800円 / 48h上限9,900円 / 72h上限14,300円
- 深夜パック: 2,640円(18:00〜翌9:00、延長は6時間まで)
- 距離料金: 20円/km(通常は20kmまで無料、深夜パックは0kmから加算)

※距離料金ステージ割引・カーシェアeチケット割引など会員固有の割引は含みません。

## ローカルでの実行

`index.html` をブラウザで直接開くだけで動作します。ビルドや依存パッケージのインストールは不要です。
