# タイムズカー料金比較

タイムズカーシェアの「深夜パック」と「通常の時間料金」を比較し、どちらが安いか一目でわかるツールです。

- 車両クラス(ベーシック/ミドル/プレミアム)を選ぶと、そのクラスの料金で計算
- 出発ステーションを名前で検索するか地図で選択(初期値はタイムズ九条駅前)。選んだクラスと出発地はブラウザに保存
- 出発時刻・利用時間・走行距離を入力すると自動で比較
- 行き先の場所名か地図のタップで、出発地からの往復走行距離を OpenStreetMap(Nominatim/OSRM)で自動計算
- ベーシッククラスは実際の利用明細(複数件)と照合し、計算ロジックの正確性を確認済み

## 料金の前提

[タイムズカーシェア公式サイトの公開料金](https://share.timescar.jp/fare/use.html)(2026年10月時点)をもとに計算しています。料金表は `pricing.js` の `CAR_CLASSES` にあります。

| クラス | 15分 | 6h | 12h | 24h | 36h | 48h | 72h | 以降1日 | 深夜パック |
|---|---|---|---|---|---|---|---|---|---|
| ベーシック | 220円 | 4,290円 | 5,500円 | 6,600円 | 8,800円 | 9,900円 | 14,300円 | 5,500円 | 2,640円 |
| ミドル | 330円 | 6,490円 | 7,700円 | 8,800円 | 11,000円 | 13,200円 | 18,700円 | 6,600円 | 3,960円 |
| プレミアム | 440円 | 8,690円 | 9,900円 | 12,100円 | 17,600円 | 20,900円 | 27,500円 | 7,700円 | 5,280円 |

- 深夜パック: 18:00〜翌9:00出発。パック終了後の延長は最大6時間までクラスの15分料金(最大時間料金なし)、それを超えた分は返却遅延料金(通常の2倍)
- 距離料金: 全クラス20円/km(通常は20kmまで無料、深夜パックは0kmから加算)

※距離料金ステージ割引・カーシェアeチケット割引など会員固有の割引は含みません。

## ローカルでの実行

`index.html` をブラウザで直接開くだけで動作します。ビルドや依存パッケージのインストールは不要です。

## テスト

料金計算ロジックは `pricing.js` にあり、`index.html` から読み込んでいます。Node.js 18 以上で次のコマンドを実行するとテストが走ります(依存パッケージなし)。

```
npm test
```
